# Minecraft 26.1.2 compatibility

## Scope
Retain the Forge 1.20.1 probe and Charger example. Add a Java 25 probe for Minecraft 26.1.2 with separate Forge 64.1.5 and NeoForge 26.1.2.114 artifacts. Preserve the HTTP envelope, authentication header, default loopback ports, and existing tool names.

## Structure
- `lab/mcdev-probe-26.1.2-common`: Minecraft 26.1.2 HTTP, client interaction, recording, and tick control sources.
- `lab/mcdev-probe-neoforge-26.1.2`: NeoForge lifecycle adapter, metadata, ModDevGradle build.
- `lab/mcdev-probe-forge-26.1.2`: Forge lifecycle adapter, metadata, ForgeGradle build.
- Existing `lab/mcdev-probe`: unchanged Forge 1.20.1 implementation.
- Plugin installation validation recognizes loader and Minecraft metadata and prevents obvious mismatches.

Separate version-specific sources avoid importing obsolete NBT, recipe, rendering, and event APIs into the old Forge project. Shared 26.1.2 sources avoid maintaining duplicate HTTP handlers. A universal cross-version jar is unsuitable because the Java and Minecraft APIs differ.

## Behavior
Support status, commands, logs, block/NBT queries, items, recipes, crafting, loot, fake players, tick control, UI snapshot/click/hover, inventory, interaction, screenshots, connect, and shutdown. Adapt component-based item data and the current recipe/display API explicitly. Report unsupported operations as errors, never as successful empty results.

Use standard mapped jars on 26.1.2. Keep the legacy Forge dev-jar restriction. Report loader/version in status and jar metadata. Retain localhost-only listeners and token checks.

## Validation
Run Node regression tests for installation and Java configuration. Compile both 26.1.2 adapters against their actual loader dependencies. Exercise a real isolated server via HTTP, including command failure, block queries, recipes, item components, freeze/step, authentication, and shutdown. Exercise client status/UI/screenshot where desktop access permits. Record unverified portions explicitly.

## Local environment
The user's PCL instance is 26.1.2 / NeoForge 26.1.2.114. Local paths belong in ignored configuration or local instructions, not general build scripts. Do not modify saves or existing mod jars. Install only the correct validated probe artifact when ready.
